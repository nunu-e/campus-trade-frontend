# Campus Trade (Frontend)

## Overview
Campus Trade is a student-focused marketplace platform that allows users to buy and sell items within their campus community. This is the frontend application built for a smooth and responsive user experience.

## Features
- User authentication UI (login/register)
- Browse and search product listings
- Create and manage product posts
- Product detail view
- Responsive design (mobile + desktop)
- Clean and modern UI

## Tech Stack
- React 
- Tailwind CSS / CSS3
- Axios
- React Router

## Backend API
Connects to Campus Trade backend API.

## Setup Instructions
git clone https://github.com/nunu-e/campus-trade-frontend.git  
cd campus-trade-frontend  
npm install  
npm run dev  

## Environment Variables
VITE_API_URL=http://localhost:5000
